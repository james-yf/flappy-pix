A flappy bird clone.

# Aims:
- learn how to make a side-scroller
- use pixel art I'm learning to make 

# What I learnt:
- how to use delta time for frame-rate independent game updates
- how to implement gravity affected player movement
- how parallax scrolling backgrounds works
- how to use masks for pixel-perfect collision detection
- how to use trig functions (sin) to make a smooth bobbing animation

# How to run:
1. `pip install pygame`

2. `python/main.py`

# Controls
- `SPACE` to start/flap
- `R` to restart the game
